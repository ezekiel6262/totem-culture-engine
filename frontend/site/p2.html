Plug your game into the Arena

See the island

Communities choose which games run in their Arena. Totem is the first. Any community can add a game to its corner of the island. Players drive, fight or solve with their Totem. Results are signed, checked, and prizes land inside the winner’s Totem.

Step 1

Describe the game

A manifest says which Totems can play, how to win and what the prize is.

Step 2

Read the Totem

Load pieces, items and credentials to build the player’s character and stats.

Step 3

Report the result

Your game server signs results. After a short dispute window, prizes pay out.

totem.game.json

{
  "name": "Meme Kart",
  "community": "totem",
  "venue": { "plot": "north-shore", "model": "circuit" },
  "entry": { "minPieces": 0 },
  "character": { "from": "totem", "stats": ["pieces", "items"] },
  "win": "first across the line, 3 laps",
  "prize": { "totem": "prefilled", "pieces": 1 },
  "reporter": "kart-server.totemtest.testnet"
}

In your game

import { Totem } from "@totem/arena";

const player = await Totem.load("<your-totem>.totemtest.testnet");
// { pieces: 3, items: ["gold-wings"], credentials: [...] }
const kart = buildKart(player.pieces, player.items);

// after the race, from your game server
await Totem.report({ game: "meme-kart", winner: player.id, proof });

Rent a Totem

Borrow a full Totem for a race or a week. You get a limited key that can play games and enter rooms. It can never withdraw tokens, sell or transfer the Totem, and it expires on its own.

Your first Totem, no gas
