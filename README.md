# Kinforge

**Launch a token. Grow a culture. Turn participation into living ownership.**

Kinforge is a programmable culture engine for NEAR. It connects durable token commitment and verified participation to evolving NFT identity, access, credentials, and gameplay. This repository is an independent NEAR Hackathon 2026 project and does not reuse any other project.

## Why it is different

NEAR already has good launchpads. Kinforge is the post-launch policy and progression layer: reusable campaign rules, anti-snapshot eligibility, provenance-bound challenge receipts, branching NFT evolution, gated utility, and auditable budget routing.

## Run locally

Serve `dist/` with any static server, for example `npx serve dist`.

The current vertical slice is intentionally deterministic and client-side. Token acquisition, elapsed time, and oracle approval are clearly labeled simulations. The rule transitions, replay/idempotency model, evolution branches, fee math, and gated experience are represented faithfully for the demo.
